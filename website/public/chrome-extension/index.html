Install the Chrome Extension

Enrich your comments with web context - element data, styles, and structure - so your agent knows exactly what you're looking at. Works in Chrome, Arc, Brave, Edge, Vivaldi, and Opera.

Download Extension
v0.3.0 · Chrome and Chromium browsers

Installation

1

Unzip the download

Extract the zip file. You'll get a folder called remarc-extension. Put it somewhere permanent - Chrome needs this folder to stay in place.

2

Open Chrome Extensions

Navigate to chrome://extensions in your address bar.

3

Enable Developer Mode

Toggle the Developer mode switch in the top-right corner of the Extensions page.

4

Load the extension

Click Load unpacked and select the remarc-extension folder you unzipped.

5

Pin it to your toolbar

Click the puzzle piece icon in Chrome's toolbar, then pin Remarc Web Context so it's always visible.

Connect to Remarc

6

Enable in Remarc settings

Open the Remarc app → Settings → Chrome Extension tab. This starts the local connection server. The status reads Waiting for extension until your browser connects in the next step.

7

Reload your browser tabs

Refresh the tabs you want to capture from. Each tab that was open before you installed needs one reload. The extension icon shows a green dot once connected, and the status in Remarc's settings turns green too.

8

Capture web context

Grab Element (⌥⇧G) highlights the element under your cursor; click to attach it to a comment. Select Region (⌥⇧R) captures a screenshot of any area of the page. Both are also in the extension popup, along with a pause toggle. Remarc saves the element's React components, computed styles, accessibility info, layout, and identity with your comment; toggle each category in Settings → Chrome Extension. The connection is local-only: it never leaves your Mac. Full details in the documentation.

Troubleshooting

⚠️

Extension shows "Disconnected"

Make sure the Remarc app is running and you've opened the Chrome Extension tab in Settings at least once. Then reload the page.

🟠

Extension icon shows an orange dot (Blocked)

The browser is blocking this site from reaching apps on your device. Open the site's permission settings and set Apps on Device to Allow (Arc calls it Loopback Network), then reload the tab. The button in the extension popup opens the right settings page for you.

⌨️

Keyboard shortcuts not working

Chrome blocks ⌘ shortcuts in extensions. Use ⌃⇧ (Ctrl+Shift) or ⌥⇧ (Alt+Shift) combinations instead. Configure shortcuts in Remarc Settings → Chrome Extension.

🔌

Connection drops after restarting Remarc

The extension reconnects automatically every few seconds. If it doesn't, reload the browser tab.

🚫

Port conflict on 9274

If another app is using port 9274, the connection will fail. Check the Remarc Chrome Extension settings for a "Port unavailable" error, close the conflicting app, then click Retry in the same settings tab to restart the server.
