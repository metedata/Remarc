title: PopClip
description: Install the Remarc PopClip extension to add a Remarc button to PopClip's action bar and open the comment composer from any selection.

PopClip is a third-party utility that pops up a small action bar when you select text. The Remarc PopClip extension adds a Remarc button to that bar. Click it to open Remarc's [comment composer](/basics/commenting-on-selections/) on your selection - it quotes the same text and anchors in the same place as Remarc's own hotkey.

## Install the extension

1. Open Settings > General. If PopClip is installed, an **Install PopClip Extension** button appears right under Detection mode.
2. Click it. PopClip adds Remarc to its action bar right away - no confirmation dialog, no security warning.

## Turn off the second popup

:::tip
Running PopClip alongside Remarc's own detection means two popups on every selection: Remarc's tooltip and PopClip's bar. Set Detection mode to Hotkey Only in Settings > General so PopClip's bar is the only thing that appears.
:::

## Troubleshooting

- **Nothing happens when you click the Remarc button.** If Remarc was not already running, macOS launches it, and it picks up the click once it opens.
- **Still nothing, and Remarc is running.** Remarc may be paused. Right-click the menu bar icon and choose Resume.
- **Pressed Install more than once?** No harm done. PopClip keeps exactly one Remarc entry in its extension list no matter how many times you click it.
