Remarc installs like any Mac app: download, drag to Applications, launch, grant permissions.

## Download and install

1. Download the ZIP from [remarc.app/download](https://remarc.app/download).
2. Unzip it and drag **Remarc** into your **Applications** folder.
3. Open Remarc. The app is signed and notarized, so macOS opens it without extra steps.

Remarc appears as an icon in the menu bar, with no dock icon by default.

## Complete onboarding

On first launch, Remarc opens a welcome window with four rows:

- **Accessibility** - lets Remarc read your selected text so comments can quote it.
- **Microphone** - used for voice dictation and speaking your comments hands-free.
- **Screen Recording** - used to capture screenshots of selected regions alongside your comments.
- **Claude Code plugin** - optional. Click **Install** to add the Remarc plugin to Claude Code in one step, or do it later from Settings > MCP Integrations.

Each permission row has an **Allow** button and a live status that flips to **Enabled** with a checkmark as soon as macOS registers the grant, without a restart. The **Continue** button unlocks once you grant all three permissions.

Close the window and finish later if you like; Remarc brings it back until setup is complete. For what each permission does and what still works without it, see [Permissions](/getting-started/permissions/).

:::tip
To open Settings, right-click the menu bar icon and choose **Preferences...**.
:::

## Launch at Login

After onboarding completes, Remarc registers itself to start at login. Turn this off anytime with the **Launch at Login** toggle in Settings > General.

## Keep Remarc up to date

Remarc checks for updates automatically and installs them via Sparkle; updates are signed. To check manually, open Settings > About and click **Check for Updates...**.
